# Hand check of the splits: the ten MAST runs of chunk 1

A split is one field at one link where the two readers give different classes and at least one of them gives a loss. Each split was read by hand against the raw link text on 2026-11-04 and 2026-11-05, by one reader, a model (claude-opus-5-5) [C]. Each was read after both model answers were in, so this reading is not blind to them. Where a verdict rests on knowledge of a library or a problem, the row says so and says "not run". Agreement between two readers is not truth, and neither is this hand. The rows below are the rows of the ten MAST runs in the hand check of the whole chunk, unchanged but for five quotes, each changed so that it is cut: two set to the link's exact spacing, one to its verbatim part, and two lines of code that hold double quotes put in code font.

## The hand rules

Written while reading, applied to every row:
- H1. A criterion on the answer ("the answer states the total") is met only by a right answer. Where the task's numbers fix the answer, I worked it out (shown in the row). A wrong or hedged answer is lost. A link with no answer of its own (a role assignment, a plan, a harness turn) does not address the criterion.
- H2. A given is carried when the link states it, changed when the link states another value or a range, and not addressed when the link names the subject without a value. It is dropped only when the link restates the setup and leaves the value out.
- H3. An evidence hop carries what its evidence holds; a note that the evidence is partial removes nothing it handed on.
- H4. An instruction or plan that states the requirement to the next agent carries it as a brief.
- H5. A review, diagnosis or report of code the link does not hand over loses nothing at that link (the v2 rule on t03 L13).
